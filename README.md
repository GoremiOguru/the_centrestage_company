## ⚡ Tech Stack & Architecture

- **Framework:** [React 19](https://react.dev/) + [Vite 8](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) with `@tailwindcss/vite`
- **Typography:** Dual editorial hierarchy pairing **Cormorant Garamond** (Serif) with **Plus Jakarta Sans** (Sans-serif)
- **Icons & Motion:** [Lucide React](https://lucide.dev/) + [Framer Motion](https://www.framer.com/motion/)

## 🚀 Getting Started

### Prerequisites
- Node.js `v18.0+`
- npm `v9.0+`

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/the-centre-stage-hq.git

# Navigate into the project directory
cd the-centre-stage-hq

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The application will run locally at `http://localhost:5173/`.

### Production Build

To build the static distribution bundle for deployment:

```bash
npm run build
```
